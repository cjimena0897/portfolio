# Claudia Jiménez · Portfolio

Static bilingual (EN/ES) portfolio on GitHub Pages: plain HTML/CSS/JS, no build step. See README.md for structure and how to add bilingual text.

## Design decisions made by Claudia (they override any skill, including `landing-page-design`)
- Typography: Playfair Display (headings) + Quicksand (body), plus Luxurious Script for the name in the hero and the big page titles. Italic quotes are fine.
- Palette: warm white base, near-black text, dark red accent `#7a0000`; greige / rose / taupe card tones. Dark mode uses a warm brown-black base with a coral accent.
- Keep the soft gradient blob in the home hero.
- No em dashes (—) anywhere in the copy. No spinning asterisk.
- Every visible text is bilingual: `<span data-l="en">…</span><span data-l="es">…</span>`.

## Content rules
- Never invent facts, metrics, quotes or results in case studies.
- Port services projects (Maintenance PSA, Personal Embarcado, Contratos y Tarifas): present the client as "a port services company in Peru"; never name the consultancy (REDPRO) or show client logos.
- Crypto Marketplace: co-designed with "another UX designer"; do not name her or link her Behance.
- Law firm website: never show the firm's name or contact details.

## Using the landing-page-design skill
Apply it for spacing, hierarchy, states, motion, accessibility and ship checks. Where it conflicts with the decisions above (single typeface, no italics, no background gradients, dark backgrounds, font list), Claudia's decisions win.
